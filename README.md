# Sandeep Kupsad Personal Portfolio

A responsive, single-page personal website designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Visit `https://YOUR-USERNAME.github.io` after deployment completes.

## Required edits before publishing

Search `index.html` for `REPLACE-WITH` and update:

- LinkedIn profile URL
- Public contact email
- Resume PDF URL

## Privacy and corporate-use check

- Confirm that all project references are suitable for public disclosure.
- Do not add confidential architecture, supplier, budget, validation, security or incident information.
- Do not use employer logos or brand assets without permission.
- Consider adding a short disclaimer that the views are personal.

## Optional enhancements

- Add a professional headshot that you own and have permission to publish.
- Add real project case studies using public or sanitised information.
- Add a custom domain through GitHub Pages settings.
- Add a privacy-friendly analytics solution only after publishing a privacy notice.
